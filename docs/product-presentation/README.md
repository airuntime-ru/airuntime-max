# Презентация продукта AIRuntime

Общая колода про платформу — без хакатона и без конкретной ниши. Та же дизайн-система, что
у `../max-presentation/` (светлые слайды чередуются с «космосом»), но бренд только AIRuntime.

| Файл | Что это |
|---|---|
| `deck.html` | исходник, 12 слайдов 1280×720 |
| `build-pdf.py` | печать в `presentation.pdf` (использует принтер из `../max-presentation/build-pdf.py`) |
| `capture-screens.py` | пересъёмка экранов кабинета с подменённым API |
| `shot-*.png`, `crop-*.png` | экраны и фрагменты экранов для слайдов |
| `qr-site.png` | QR-код на airuntime.ru для финального слайда |

## Структура

1. Обложка — «Опишите идею. И она полетит», кабинет и чат на телефоне
2. Проблема — почему разработчик, конструктор и AI-генератор кода не закрывают задачу
3. Решение — один чат от описания до ссылки в проде
4. Главное отличие — живой продукт, а не архив с кодом
5. Платформа — базы по запросу, секреты вне модели, версии
6. Под капотом — оркестрация агентов и проверка доказательствами
7. Что можно сделать — сценарии с готовыми формулировками
8. Для кого — три сегмента с лендинга
9. Сравнение с привычными способами
10. Бизнес-модель — тарифы, свой ключ, наценка, домены
11. Безопасность и доверие
12. Финал с QR

Цифры тарифов — из `frontend/src/components/landing/pricing-section.tsx` (они же в миграции
тарифов). Поменялись тарифы — поправить слайд 10.

## Пересобрать

```bash
cd docs/product-presentation
python build-pdf.py
```

## Переснять экраны

Кабинет открывается с подменённым API, поэтому нужен только фронтенд. Снимать с
production-сборки (`npm run build && npm run start` в `frontend/`): в dev-режиме Turbopack
вложенные страницы проекта (`/app/projects/<id>/chat` и т. п.) отдают 404.

```bash
python capture-screens.py
```

Все данные на экранах демонстрационные: проекты, чат и логи придуманы для показа.
